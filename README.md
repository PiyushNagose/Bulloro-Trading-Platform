# Bulloro Trading Platform

This repository contains three apps:

- `Backend`: Express and MongoDB API for auth, holdings, positions, and orders
- `Frontend/frontend-app`: public landing site
- `Dashboard/dashboard-app`: authenticated trading dashboard

## Local setup

1. Create env files from the examples below.
2. Install dependencies in each app folder with `npm install` if they are not already present.
3. Start the backend from `Backend` with `npm start`.
4. Start the frontend from `Frontend/frontend-app` with `npm run dev`.
5. Start the dashboard from `Dashboard/dashboard-app` with `npm run dev`.

## Environment files

- `Backend/.env.example`
- `Dashboard/dashboard-app/.env.example`
- `Frontend/frontend-app/.env.example`
